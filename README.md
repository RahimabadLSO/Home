# RLSO — Rahimabad Local Support Organization®

Official website for the Rahimabad Local Support Organization (RLSO), a registered non-profit serving Union Council Rahimabad, Punjab, Pakistan.

## How to Deploy on GitHub Pages

### Step 1 — Create a GitHub Repository
1. Go to [github.com](https://github.com) and sign in
2. Click **New repository** (the `+` icon → New repository)
3. Name it: `rlso-website` (or any name you prefer)
4. Set it to **Public**
5. Click **Create repository**

### Step 2 — Upload the Files
1. In your new repository, click **Add file → Upload files**
2. Upload all of these files:
   - `index.html`
   - `_config.yml`
   - `.nojekyll`
   - `README.md`
3. Click **Commit changes**

### Step 3 — Enable GitHub Pages
1. Go to your repository **Settings** tab
2. Scroll down to **Pages** in the left sidebar
3. Under **Source**, select **Deploy from a branch**
4. Choose **main** branch and **/ (root)** folder
5. Click **Save**

### Step 4 — Access Your Website
- GitHub will provide a URL like: `https://your-username.github.io/rlso-website/`
- It may take 1–2 minutes for the site to go live after enabling Pages

## Files
| File | Purpose |
|------|---------|
| `index.html` | Main website (all content, styles, and scripts) |
| `.nojekyll` | Tells GitHub Pages to skip Jekyll processing |
| `_config.yml` | GitHub Pages configuration |
| `README.md` | This instructions file |
